# Recording and rehearsal

Use a dedicated browser profile and only the fictional workshop. Open the app once online and wait for the production service worker. Open Settings and choose **Prepare on-device model** while online. Check Chrome's on-device internals if the model needs a download. Use a fresh test study rather than replacing a researcher's workspace.

| Shot | Action and visible proof |
| --- | --- |
| 0–20 s | Open the fictional workshop and show the Saturday preference beside P05’s inability to attend. Show P03's repeated comments. |
| 20–52 s | Select P05, clear the example cards for that interview by editing its note, then set the tab's network to Offline and reload. Open P05 again. Choose Suggest evidence, wait for confirmed on-device output and show the exact quote. Label any shortened wait. |
| 52–82 s | Open Review evidence. Approve one card, edit its sharing text to remove an identifying detail and show approval clearing. Approve the intentionally shared cards. Open the exact payload preview and inspect the question, IDs, pseudonyms and excerpts. |
| 82–110 s | Restore the network. Send the approved packet. Show the actual returned origin and evidence. Inspect a minority citation and its original local source. Verify the displayed counts before narrating specific numbers. |
| 110–140 s | Edit a finding, narrow its wording and change a questionable citation to neutral or uncertain if warranted. Save. Show the updated counts and renewed review requirement. |
| 140–160 s | Review each finding, inspect the uncited excerpts and confirm overall review. Preview and download the printable HTML. Open the file and use the browser Print dialog for PDF. Change an approved excerpt and demonstrate stale-export blocking. |

**Recovery.** If local AI is unavailable, show manual exact-quote capture and identify it on screen. If cloud quota is exhausted, use a previously recorded genuine run with its date and origin visible, or use the distinctly labeled written example. Never call a written example live inference. After a source edit the written example's fixed counts may no longer be available. Start a fresh fictional study if using the written route. Review all findings before enabling export.

**Recording checks.** Capture the app tab only. Hide unrelated tabs, account identifiers, debug consoles and credentials. The rules require an English or English-subtitled video made publicly visible on YouTube with its link on the submission form. Keep the cut under three minutes.
