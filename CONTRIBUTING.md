# Contributing

Use a current Node 24 installation, install with `npm ci`, and start the Vite app with `npm run dev`. The fictional example and complete manual workflow run without a Firebase account.

Use synthetic examples in tests, screenshots and issues. Keep secrets in ignored local configuration. Changes touching ingestion, sharing, participant identity or reports should exercise both the allowed path and an invalidated or rejected path. Preserve the source metadata checks, strict inference modes and exact preview boundaries. See [architecture](ARCHITECTURE.md) and [testing](TESTING.md).

Run the full test suite and production build before opening a pull request. Describe observed results, any untested behavior and changes to stored data. Keep model-quality claims separate from programmatic validation. Contributions use the repository's MIT license.
